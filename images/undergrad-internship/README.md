# KURF internship figures

Figures from the King's Undergraduate Research Fellowship project (summer 2022, Centre for
Developmental Neurobiology, King's College London, with Dr Fursham Hamid and Professor Eugene
Makeyev): "Regulation and biological functions of alternative splicing in neurons of the adult
mice visual cortex". Single-cell and single-nucleus RNA-seq of matched mouse cortical neurons
were compared to find splicing events that send transcripts to nonsense-mediated decay.

For the splicing project page (`_portfolio/KURF.md`).
