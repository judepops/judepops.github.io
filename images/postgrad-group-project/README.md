# MRes group project figures

Workflow figures from the MRes group project at Imperial College London (January to March 2024)
with Dr Ximena Montano at King's College London: mapping cell types in NanoString CosMx spatial
transcriptomics data from 13 neuroblastoma tumours, using a single-cell reference atlas built
for the project.

For the neuroblastoma project page (`_portfolio/CISBIO.md`).

| Image | What it shows | Source |
| --- | --- | --- |
| `neuroblastoma-atlas-workflow.png` (hero) | Building the single-cell reference: public datasets merged and batch corrected, then annotation, the sympatho-adrenal subset, pseudotime, a control adrenal dataset, copy number detection and a pathway analysis | Project figure (web copy of `images/cisbio_1.png`) |
| `neuroblastoma-spatial-workflow.png` | The spatial workflow: CosMx samples and the integrated atlas, then cell type annotation, spatial clusters with SiGra, key genes, differential abundance by stage and ligand-receptor interactions | Project figure (web copy of `images/cisbio_2.png`) |

These are web-optimised copies of the two figures the site already used. Sizes are recorded in
`_cowork/scripts/prepare_postgrad_images.py`; context is in
`_cowork/notes/postgrad/02_group_project_neuroblastoma.txt` (local only).
